# Consistency and Branding
## What Is Design Consistency?

Consistency means that similar elements look and behave the same way throughout a website. Every button uses the same style. Every heading follows the same type scale. Every page uses the same color palette and spacing. When a visitor moves from one page to the next, the experience feels seamless.

Inconsistency — where buttons change color, fonts shift between pages, or spacing feels random — makes a site feel unpolished and unpredictable. Users lose confidence in a site that doesn't present itself cohesively.

## The Elements of Consistency
- Colors — Use the same palette everywhere. Primary buttons should always be the same color. Links should always look like links.
- Typography — Stick to the same fonts, sizes, and weights. An h2 heading should look the same on every page.
- Spacing — Use the same margin and padding values. If sections are separated by 48 pixels of space on one page, the same rule should apply site-wide.
- Components — Buttons, cards, forms, and navigation should follow the same visual pattern. A card on the homepage should look like a card on an inner page.
- Tone and voice — The writing style should feel consistent too. If the homepage is friendly and casual, a legal page shouldn't suddenly switch to cold, corporate language.

## What Is Branding?
Branding is the overall identity of a website or company — the combination of visual design, voice, values, and personality that makes it recognizable. Good branding means that if someone saw just a button, a color, or a snippet of text from your site, they could identify it as yours.

On the web, branding is expressed through:

- Logo — The visual mark that represents the brand, placed consistently (usually top-left in the header).
- Color palette — A set of colors that are uniquely associated with the brand.
- Typography — The fonts that feel like "yours" and appear across the site and marketing materials.
- Imagery style — Whether photos are bright and candid, dark and moody, or replaced by illustrations and icons.
- Voice — The way the brand communicates — playful, serious, technical, friendly, minimal.
